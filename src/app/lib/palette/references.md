# Colour calculation contracts

- WCAG 2.2 relative luminance and contrast: https://www.w3.org/TR/WCAG22/#dfn-relative-luminance . Black/white=21, identical=1, #777777/white=4.478089453577214. Evaluate unrounded values; normal AA 4.5, large AA 3, normal AAA 7. No palette-wide conformance claim.
- Existing OKLab transform retained. Red L=.6279553606 from Björn Ottosson's reference transform: https://bottosson.github.io/posts/oklab/ . Chroma reduction at fixed lightness/hue is this application's sRGB gamut policy, not CSS Color 4 gamut mapping.
- APCA 0.0.98G constants / apca-w3 0.1.9. Signed Lc, informational and separate from WCAG 2. Fixture values obtained by executing upstream APCAcontrast(sRGBtoY(fg),sRGBtoY(bg)), downloaded 2026-10-28: https://github.com/Myndex/apca-w3/blob/master/src/apca-w3.js . Source SHA256 7980633564cc5749aad608f163ad1a015af57f573729af2ea081034458ab79fe. Andrew Somers, W3 licensed reference. Interpret contrast alongside font size and weight; Lc is not a universal pass threshold.
- Colour difference is Euclidean OKLab in native units (black/white distance 1). No CIEDE2000 claim. Diversity % is a clipped/averaged heuristic normalized against .3 distance, not a measurement unit or proof of palette quality.
- CVD simulation: Brettel 1997 with Smith/Pokorny 1975, sRGB white neutral, severity 1. Public-domain precomputed coefficients by Nicolas Burrus: https://github.com/DaltonLens/libDaltonLens/blob/master/libDaltonLens.c . Independent test outputs were generated by compiling that C implementation with cc on 2026-10-28; allow one byte for float/rounding differences. These are approximations, not disability-specific accessibility certification. All three modes use piecewise projections in linear light, then sRGB encode/clip.

Known limits: finite fixtures do not establish universal perceptual fidelity. Achromatic seed hue is an implementation convention. Semantic-role separation and aesthetic tuning are heuristics. Locked/edited values always take precedence; report failing pairs instead of silently changing user choices.

Additional gamut fixtures: `docs/studio-audit/gamut-reference.json` was generated with independently installed ColorAide 8.13.1 on 2026-10-28. Each out-of-gamut OKLCH input was converted by ColorAide; a separate 100-step Python bisection applied this application's fixed-L/H policy and encoded sRGB tolerance [-.001,1.001]. Frozen chroma boundaries (tolerance 5e-7) and quantized hex outputs are executable fixtures. This validates finite cases of the application policy, not CSS gamut-mapping conformance. ColorAide conversion documentation: https://facelessuser.github.io/coloraide/api/ .

Exact neutral sRGB inputs use C=0/H=0: hue is powerless for zero chroma (https://www.w3.org/TR/2024/CRD-css-color-4-20240213/#specifying-oklab-oklch). Zero is the application's deterministic convention, rather than a numerical hue inferred from matrix rounding residuals. Nonneutral inputs retain the existing transform.
