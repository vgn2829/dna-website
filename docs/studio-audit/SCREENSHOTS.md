# Native Safari screenshot index

Captured in Safari Responsive Design Mode at the named logical CSS widths and 900px viewport height. Page zoom was 100% unless the filename says zoom200. The preview fit scale (86%) and pixel ratio (2x) are separate from page zoom. PNGs are cropped from native captures to the local viewport; browser chrome and other tabs are excluded. These are desktop Safari viewport checks, not physical-device certification.
